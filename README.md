# Reverse Engineering & Forensics Course
that's a brief intro into how the course will look like

Интерактивный образовательный курс по информационной безопасности, объединяющий теорию, практические задания и CTF-задачи.

## Платформа

Проект будет реализован в формате **сайта-курса**, позволяющего самостоятельно освоить основы информационной безопасности и получить знания более продвинутого уровня (ориентировочно B1).

Мы не стремимся охватить абсолютно все направления ИБ. Наша цель — создать полноценное и удобное для изучения пособие по темам, качественных структурированных материалов по которым пока недостаточно.

Для некоторых направлений уже существуют отличные образовательные платформы:

- **Web Security** — [PortSwigger Web Security Academy](https://portswigger.net/web-security)
- **Cryptography** — [CryptoHack](https://cryptohack.org/)
- **Binary Exploitation (PWN)** — [pwn.college](https://pwn.college/)

Однако материалы по **Digital Forensics** и **Reverse Engineering** зачастую разрозненны: теорию и практику приходится искать в разных источниках, а многие руководства требуют предварительных знаний.

Именно на этих двух направлениях мы хотим сосредоточиться, объединив теорию, подробные объяснения с примерами и практические задания в единую систему обучения.

Кроме того, для полноценного изучения этих тем необходимы базовые знания **Linux и компьютерных сетей**. Поэтому соответствующие разделы также будут включены в курс.

### Особенности платформы

- **Сохранение прогресса без регистрации.** На главной странице пользователь получает уникальный токен, который служит его идентификатором и позволяет восстанавливать сессию. Токен необходимо сохранить для дальнейшего использования.

- **Практика на протяжении всего курса.** Каждая тема сопровождается практическими заданиями. Предусмотрены как интерактивные упражнения с выполнением команд непосредственно на сайте (см. макеты выше), так и полноценные CTF-задачи. Последние будут представлены в конце каждого модуля в виде набора из нескольких заданий разной сложности.

- **Возможность создания собственных материалов.** Пользователи смогут предлагать свои темы и статьи с помощью встроенного редактора. Перед публикацией все материалы будут проходить модерацию.
